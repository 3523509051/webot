# 后台浏览器搜索、高德天气与网站读取（v0.15.1）

## 后台浏览器搜索

`web_search` 通过 Windows 桥接启动独立、后台运行的 Edge，由 Playwright 打开搜索首页、
填入关键词并提交原生 GET 表单，然后读取结果页中的标题、链接和摘要。
默认使用必应网页版，不再调用百度 AI 搜索 API，也不读取或要求百度 API Key。
结果页最多取 6 条，每条摘要最多 300 字；需要正文时再调用 `read_website`。

本机 `bridge/config.json` 的 `website.search_engine` 可设为 `bing`（默认）或 `baidu`（网页版）。
`browser_channel=msedge`、ping 严格小于 300ms 和已有依赖安装步骤仍适用。
搜索浏览器不读取个人资料或登录态，临时会话中的搜索 Cookie 在浏览器关闭后丢弃。
网站脚本、图片、视频、下载及额外请求被阻止，仅保留搜索页面和原生 GET 表单导航。
浏览器实际接收并解析搜索页面 HTML；每次导航通过公网地址、ping 和固定IP的网络检查，
重定向仍复核，网页搜索阶段只允许搜索引擎自身域名。结果站点不会自动访问；读取正文另走网站工具。

搜索结果先做关键词和模型内容审核，最终回复再审核；审核失败不返回原文。
搜索整体最多等待 40 秒，默认本实例跨群每天最多 50 次，失败、取消、无结果也计数。
这是本地资源上限，不是百度免费 API 次数。搜索与网页读取共享单个浏览器工作锁，避免并发占满服务器内存。
遇到验证码、反自动化限制或搜索页结构变化时会停止并说明原因，不绕过验证，也不退回百度 API。
实现参考 [Playwright 网络路由文档](https://playwright.dev/python/docs/network)。

## 高德配置

在高德开放平台申请 **Web 服务 API** 类型的 Key，并确认地点搜索、路径规划权限。
参考 [高德路径规划文档](https://developer.amap.com/api/webservice/guide/api/direction) 和
[地点搜索文档](https://developer.amap.com/api/webservice/guide/api-advanced/search)。
在仓库根目录本机 `.env` 中添加 `AMAP_WEB_KEY=你的Key`，不要填入跟踪的插件配置或发到群里。
重新创建容器，使环境变量生效：

```powershell
docker compose up -d --force-recreate astrbot
```

插件提供 `amap_places` 和 `amap_route`。只有当前批次明确 @ 机器人的地图/旅行请求可以调用，
多人批次按发送者 ID 授权。路线支持同城驾车、步行和公交，按指定顺序查询 2～6 个地点。
模糊地名会要求选择具体地点，不会自动取第一条结果。每次地点搜索、每段路线各计一个请求，
默认本实例跨群合计每天最多 100 次；失败也占用本地额度，这不等于高德账户的剩余额度。

测试例子：真正 @ 机器人发送「请规划杭州三日旅游路线，公交为主，出发点杭州东站」。
模型应先询问日期、预算、偏好和具体地点，再查询路线；不能把交通耗时当成完整游玩时间。
该工具不购买门票、不预订住宿，不提供跨城公交或自动全局最优排序。

## 天气直接走高德

`amap_weather` 独立处理已放行的天气问题，不需要用户额外说「联网」或「搜索」。
真正 @ 发送「深圳现在天气怎么样？」查询实况；「深圳明天天气怎么样？」查询短期预报。
缺少城市先询问，不能根据群名或其他群员的位置猜测。城市名先用行政区查询转换为 adcode，
重名地区要求明确位置；纯 6 位行政区编码可直接查询。省级地区（直辖市除外）需要具体到城市/区县。
天气数据注明高德来源和 `reporttime`，只回答接口实际返回的预报日期。
高德无数据、权限不足、超时或超出预报范围时说明原因，不使用百度搜索补查，也不编造天气。
行政区查询和天气查询分别计入共享高德日额度。

参考 [高德天气 API](https://lbs.amap.com/api/webservice/guide/api/weatherinfo)
和 [行政区域 API](https://lbs.amap.com/api/webservice/guide/api/district/)。

## 宿主机浏览器

在 Windows 桥接虚拟环境安装依赖，并安装 Microsoft Edge：

```powershell
.\bridge\.venv\Scripts\python.exe -m pip install -r bridge\requirements.txt
```

重启微信桥接。浏览器使用独立临时上下文、后台运行，不使用个人浏览器的登录态。
它只渲染已提取并转义的网页文字，网页脚本、样式、图片、视频、iframe 均不加载。
因此这是受限的文字读取工具，不能操作整个桌面，也不支持必须执行 JavaScript、登录或验证码的网站。
实现使用 [Playwright](https://playwright.dev/python/docs/browsers)。

在被 Git 忽略的 `bridge/config.json` 中可加入 `website`，格式见 `bridge/config.example.json`：

- `enabled`：默认 `true`。
- `restrict_domains`：默认 `false`，不限制国内或国外域名；改为 `true` 才启用白名单。
- `allowed_domains`：仅在 `restrict_domains=true` 时生效，允许列表中的域名及子域名。
  空列表会拒绝所有网站。不要使用通配符；如需增加站点，填实际域名，不要仅填 `com` 或 `cn`。
- `max_ping_ms`：默认 `300`；必须 ping 成功且平均回复延迟严格小于此值。
- `browser_channel`：默认 `msedge`，需安装 Edge；改成其他浏览器须按 Playwright 文档安装。

请求例子：真正 @ 机器人发送「请访问 https://github.com/3523509051/webot ，看看部署说明」。
网页读取和后台浏览器搜索在正常放行的对话中始终可用，不再校验批次授权名单、发送者ID或网址是否出现在本批次。用户未提供网址时，可以先搜索官网，再读取搜索结果；也可以继续读取近期对话中需要的页面。HTTP、HTTPS、裸域名和中文域名均支持。
无需每次重新提供网址或放权。发送「不要访问了」会停止该发送者的旧请求；
已进行中的网络请求可能已发出，但晚到内容不再提供给回答。

## 检查顺序与内容过滤

访问前检查 HTTP/HTTPS、标准端口和 DNS；全部解析地址必须是公网地址。域名白名单默认关闭。
请求固定使用已经检查并 ping 的 IP，保持 HTTPS 证书验证，每次重定向重新检查。
本机、内网、云元数据地址、账号密码 URL、文件下载、媒体响应、超过 500KB 的网页均拒绝。
全流程读取最多等待 25 秒；浏览器读取不阻塞其他群消息发送。默认本实例所有群合计每天读取最多 300 次，失败也计数。

抓取后先用保守关键词规则检查完整文字，再对最多 8000 字的返回内容调用当前默认模型审核。
色情、血腥暴力等命中、模型审核失败、超时、格式异常或判断不确定时，不返回原文。
网站相关最终回复在发送前再次审核，强制仅文字；流式内容先收集后审核，不提前发送。
一次成功读取通常增加两次内容审核模型调用；会有漏判和误判风险，不能作为绝对安全保证。
不读取图片和视频，因此不声称完成图片或视频的内容识别。

若手动启用白名单，它只定义允许访问的范围，不证明网站所属国家或网站安全。
能 ping 通且延迟低仅代表连通性，不代表网站无恶意。
网页返回的是不可信资料，不允许把其中的指令当成群员授权。网站返回的链接、脚本和文件不会自动执行。

## 本机与服务器验收

离线回归覆盖授权、撤回、白名单、内网地址、危险跳转、延迟、媒体、大小、内容审核和流式输出。
高德真实请求需要配置 Key 后另测；未配置时应明确返回缺少 Key。
网站实际访问还受当前网络的 ICMP 限制：禁 ping 的正常网站也会被拒绝，这是所选严格规则的预期结果。
密钥、计数、日志和本机验证脚本分别在 `.env`、`data/`、日志目录和 `scripts/local/`，均不上传 GitHub。
