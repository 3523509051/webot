# 源码发布检查清单

日期：2026-11-22。当前定位为 Windows 微信桥源码预览。

## 发布内容

- 当前桥实现：统一群／私聊读取、授权门、身份及资源来源、文字与媒体动作、发送回执。
- 配置示例、依赖声明、README、工程图及桥接契约。
- 已在仓库中的旧 AstrBot 组合和文档保留为兼容／历史材料；它们不是 Pero 的启动器。

## 排除内容

真实 .env、bridge/config.json、微信数据库及密钥、联系人和聊天资源、日志、文件／表情运行库、部署暂存目录、交接报告、一次性压测脚本及本机备份不作为本次发布内容。默认静态表情素材与运行时收录内容分别处理。

## 核对范围

1. 当前文件及历史文本分别检查，避免只删除当前文件却继续携带敏感旧内容。
2. 公开提交不包含已识别的历史压测脚本；检查记录不复述任何凭据原值。
3. 核对 Python 语法、桥模块依赖、示例 JSON 与 README 相对链接。
4. 群／私聊、媒体回执和队列行为采用已有定向验证及实际部署记录；不将本次静态发布检查称为全新机器微信实测。
5. 核对最终提交树与远端分支；远端历史改写需要单独确认，并保留本地原开发历史。

## 边界

依赖及微信版本需按实际 Windows 桌面验证。语音发送、完整 OneBot 实现及任意类型文件发送不作为本次支持承诺。主仓库许可证见根目录 LICENSE。
