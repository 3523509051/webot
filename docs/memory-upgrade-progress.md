## 已上线的主体功能

| 功能 | 实际交付 |
| --- | --- |
| 统一身份 | wxid 与桥用户 ID 一致；保留有来源的别名；同名/近似名字不自动合并。真实数据中 Amy 可查陈sir的4条原画像，名字相近的另一人保持独立 |
| 原文与 L2 | SQLite 持久记录独立于500条热视图，通常注入最近200条并有字数预算；更早原文可查询 |
| 明确记忆 | 程序处理明确保存，真实事务回执；支持多事项、修改、取消、相对日期，区分交代者与事项主体 |
| 日记与总结 | 后台按量/空闲分块整理，保留来源；跨上海日期拆分，按日索引支持安静日期；摘要失败不删除原文 |
| 回答前检索 | 人物、日期与话题筛选；人物未知时不把他人事项作为“我的”；程序提供证据和查询状态，语义补查及结果检查 |
| L20 | 工具实际结果与图片编号/已有文件名、文件版本/读取范围等摘要关联到回复，仅供模型历史读取；目录查询不等于读过内容 |
| 范围与清理 | 所有监听群启用；物理自动清理关闭。贝蒂未改；现有记忆保留，等待用户自行清除 |
