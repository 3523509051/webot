## 需求对照

供 Pero 组合启动器调用，扫描全部群并输出本机结果；桥继续负责微信收发，微信客户端由用户手动启动和登录。该入口不调用旧 AstrBot 启动脚本，不打开微信程序。

## 代码与兼容

scan_groups.py 使用既有 WeChatDB 和目录定位接口。有效账号、非空群及合法群名缺失时明确失败，不输出假成功。输出文件是运行数据，由调用方临时管理。main 与扫描过程检查本目录互斥，不按进程名杀其它程序。

astrbot.token_env 设置后只从该环境变量取令牌，不回退旧 JSON token；未设置时保留原配置方式。run_managed.py 只托管桥循环和停止请求，日志写入调用方指定的本机目录。

## 验证

模拟数据库验证扫描规范化与空扫描拒绝，跨进程验证互斥锁及释放；全部不启动微信。结合真实 Pero／Manager 的模拟桥联调通过全群配置、连接认证、群关闭及重扫保持。Python 语法、配置 JSON、文档链接均核对。

## 提交卫生与边界

从上次已清理的 main 追加本轮变更，未引入旧本地开发历史。没有真实令牌、群清单、bridge/config.json、数据库、日志或部署备份。实际客户端扫描和发送仍需用户在已登录环境确认，本轮没有进行微信实机操作。
